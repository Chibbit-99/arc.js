ARC.JS / USING ARC.JS

Build a browser project with ARC.js.

The usual flow is simple: load main.js, create an arc/ directory, describe your project in config.json, optionally set up dependencies in arc/init.js, and write your application in src/.

Quick start

Start with a normal HTML page and load the ARC.js runtime.

<!doctype html>
<html>
<body>
    <h1>My ARC.js app</h1>

    <script src="https://chibbit-99.github.io/arc.js/main.js"></script>
</body>
</html>

ARC.js then looks for ./arc/config.json relative to the page.

my-project/
├── index.html
├── arc/
│   ├── config.json
│   └── init.js
└── src/
    └── main.js
You do not need a package.json for ARC.js itself. The browser project is described by config.json.

Project layout

index.html

Your webpage. Load the ARC.js runtime with a script tag.

arc/config.json

Declares runtime modules and the project JavaScript files you want ARC.js to execute.

arc/init.js

Optional setup code. Useful for importing packages or creating globals before your application starts.

src/

Your application code. ARC.js can execute one file or several files listed in js.

Configure your project

The smallest useful configuration uses the NPM loader and one entry file.

{
  "modules": ["npmloader.js"],
  "js": ["./src/main.js"]
}

Modules

Put module filenames in the modules array. They are loaded from the ARC.js module directory before your initialization code runs.

JavaScript files

js accepts either a single string or an array.

// One file
{
  "modules": ["npmloader.js"],
  "js": "./src/main.js"
}

// Several files
{
  "modules": ["npmloader.js"],
  "js": [
    "./src/components.js",
    "./src/main.js"
  ]
}

Use arc/init.js

arc/init.js is optional. When it exists, ARC.js executes it before the project JavaScript files and waits for it to finish.

const three = await importPackage("three");

globalThis.THREE = three;

This makes initialization code a convenient place to prepare libraries that the rest of your application will use.

ARC.js executes init.js as an async function, so await importPackage(...) can be used directly.

Write your application

Once the runtime has loaded, the files in js are executed as browser JavaScript.

// src/main.js

console.log("ARC.js is running");

document.body.insertAdjacentHTML(
    "beforeend",
    "<p>Hello from the project entry point.</p>"
);

When there are multiple entries, ARC.js fetches them concurrently and then executes them in configuration order.

Use NPM packages

The included npmloader.js module adds browser-side NPM imports.

const THREE = await importPackage("three");

const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(
    70,
    window.innerWidth / window.innerHeight,
    0.1,
    1000
);

console.log(scene, camera);

The same API is used by the repository's Three.js example.

importPackage()

await importPackage(specifier)
Loads a package and returns its module namespace. The package is resolved, bundled for the browser, and then cached for reuse.
const tesseract = await importPackage("tesseract.js");
const three = await importPackage("three");

The runtime exposes the function globally, so there is no separate ARC.js import statement to write.

importGlobal()

importGlobal(packageName, exportKey, alias)
Copies one export from an already imported package onto globalThis.
await importPackage("three");
importGlobal("three", "ArrowHelper");

// Optional alias:
importGlobal("three", "Vector3", "Vec3");
The package must already be imported. importGlobal() does not perform package loading or network requests.

Versions and subpaths

You can request a particular package version or package subpath.

const exact = await importPackage("three@0.180.0");
const helper = await importPackage("some-package/helpers");
const both = await importPackage("some-package@1.2.3/helpers");

The loader understands common version ranges such as exact versions, major/minor versions, wildcards, ^, ~, and comparison expressions.

Debugging

Open your browser's developer console to see ARC.js startup messages. Runtime and package-loader messages use the [ARC] prefix.

console.log(ARC);

const three = await importPackage("three");
console.log(three);

The global ARC object exposes runtime state useful for debugging, including loaded package/module caches.

What ARC.js does for you

You provide the HTML page, configuration, optional initialization, and application code. ARC.js handles the startup sequence and, when npmloader.js is enabled, the browser-side work needed to turn an NPM package into something your application can use.
