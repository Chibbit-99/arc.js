JavaScript.
Reimagined.

ARC.js is a lightweight browser runtime for dynamically loading modules, importing NPM packages, and experimenting with what JavaScript can do.

View on GitHub Read the docs Try the Three.js demo Explore ARC.js 
// Import an NPM package directly through ARC.js.

const three = await importPackage("three");

// Packages can then be used by your browser code.
console.log(three);

Built around the runtime.

Dynamic modules

Load JavaScript modules at runtime instead of rebuilding your entire application.

NPM in the browser

Bring packages from the NPM ecosystem into your browser environment with ARC.js's package loader.

Config-driven loading

Use config.json to declare runtime modules and application entry points without hard-wiring everything into one script.

Extensible modules

ARC.js loads functionality through modules, keeping the core runtime separate from optional features.

Browser-first

Run the runtime directly from a static site. No Node.js server is required just to experiment with it.

Built to experiment

ARC.js is intentionally small and flexible, making it a place to try ideas around browser-side JavaScript runtimes.

How the project fits together.

main.js

The main ARC.js runtime. It loads the configuration, discovers the requested modules, and starts the configured JavaScript entry point.

module/npmloader.js

The NPM loader module. It provides the package-loading layer used by importPackage(), including browser-side package extraction and loading.

demo/arc/

A minimal example showing the basic ARC.js project layout: config.json, init.js, and a src entry point.

demo/threejs/

A larger example using the same runtime to load Three.js from NPM and run a browser-based 3D demo.

ARC.js + Three.js

See it running.

The Three.js example is a real project inside the ARC.js repository. It uses ARC.js to load the three package and build a browser 3D scene.

What if the browser
could do more?

ARC.js is an experiment in giving browser JavaScript a more flexible runtime. The project is built around a small core, optional runtime modules, configuration-driven startup, and a package loader that brings parts of the NPM ecosystem into the browser.
