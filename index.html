WHY ARC?

Built around the runtime.

01 //

Dynamic modules

Load JavaScript modules at runtime instead of rebuilding your entire application.

02 //

NPM in the browser

Bring packages from the NPM ecosystem into your browser environment.

03 //

Modular by design

Extend ARC.js through modules without needing to modify the core runtime.

THE IDEA

What if the browser
could do more?

ARC.js is an experiment in giving browser JavaScript a more flexible runtime. No massive framework. No unnecessary abstraction. Just a small core with room to grow.
